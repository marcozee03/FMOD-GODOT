FmodEventAudioStream
====================

**Experimental:** This class was added to support sound themes in godot 4.8 the implementation is somewhat hacky so if you find any bugs open a github issue. For now FmodEventEmitter classes are the preferred way to play sounds using nodes but, in the future they may be deprecated to prefer AudioStreamPlayers and AudioStreams
