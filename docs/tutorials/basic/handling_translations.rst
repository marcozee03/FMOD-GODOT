Handling Translations
======================

FMOD outputs it localizations as seperate banks. ie Menu.En.bank and Menu.Es.bank. You can use
Godot's built in resource remapping see `localizing resources`_.

.. _localizing resources: https://docs.godotengine.org/en/stable/tutorials/i18n/internationalizing_games.html#localizing-resources
